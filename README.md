# Deep Time

Two Android-first casual games sharing one ad-revenue brain and one design system.

- **Dino Break**: brick breaker across ten eras of Earth history.
- **Dino Match**: match-3 with prehistoric stones and crystals.
- **ad-brain** (planned): reusable, engine-agnostic ad logic. Interstitial and rewarded video, streak-aware, probabilistic, with a daily budget and hard limits in code.
- **design-system/**: the Deep Time tokens, 12 React components, era palettes and usage rules. Start with `design-system/README.md`.

Stack: Vite JS, wrapped with Capacitor for Android. Release through GitHub Actions to Google Play.

Status: design system done. No game or ad-brain code yet.
